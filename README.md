# منصّتي — تنظيم كل الأشغال في مكان واحد

منصّة شخصية تجمع كل مجالاتك (إدارة فرق، تعليم، جامعة، دوام، جلسات تصوير، جمعية، إدارة أملاك…)
في **تقويم واحد** مع **مهام** و**متابعة مبالغ** و**تقرير شهري تلقائي** يُظهر ما أنجزته
وما تعثّر وما يجب تلافيه الشهر القادم.

تعمل بالكامل داخل المتصفّح: بدون إنترنت، بدون حساب، وبدون خادم — وبياناتك تبقى على جهازك.

---

## التشغيل

### محليًا
```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
أي خادم ملفات ثابت يفي بالغرض. (فتح `index.html` مباشرة يعمل أيضًا، لكن ميزة العمل بدون
إنترنت تحتاج خادمًا لأن `Service Worker` لا يعمل من `file://`.)

### نسخة الملف الواحد
```bash
./build.sh
# ينتج dist/index.html — ملف واحد يعمل بالنقر المزدوج ويسهل نقله لأي جهاز
```

### على الجوال
1. ارفع الملفات على أي استضافة ثابتة (GitHub Pages مثلًا).
2. افتح الرابط في المتصفّح.
3. من قائمة المتصفّح اختر **«إضافة إلى الشاشة الرئيسية»** — تصير كالتطبيق تمامًا وتفتح بدون إنترنت.

#### النشر على رابط مستقل (GitHub Pages)
المستودع فيه `.github/workflows/pages.yml` ينشر تلقائيًا مع كل دفعة. لتشغيله مرة واحدة:

**Settings ← Pages ← Source: GitHub Actions**

بعدها يصير للمنصّة رابطك الخاص:
```
https://<اسم-حسابك>.github.io/my-self/
```
ويتحدّث تلقائيًا مع كل تعديل. وتقدر تربطه بنطاق خاص بك من نفس الصفحة (Custom domain).

## الشاشات

| الشاشة | ماذا تفعل |
|---|---|
| **اليوم** | مواعيد اليوم، المهام المتأخرة أولًا، ما استحق اليوم، ما يقترب خلال ٣ أيام، وما أنجزته |
| **التقويم** | شهر كامل ملوّن حسب المجال، مع لوحة تفاصيل لأي يوم تختاره + التاريخ الهجري |
| **المهام** | إضافة وتعليم الإنجاز، فرز حسب المجال والأولوية والحالة (مفتوحة / متأخرة / منجزة) |
| **المالية** | محصّل وغير محصّل لكل شهر، توزيع على المجالات، وتنبيه بالمستحقات التي فاتت |
| **التقرير الشهري** | تحليل تلقائي كامل + طباعة/PDF + أرشيف الشهور السابقة |
| **الإعدادات** | تعديل المجالات وألوانها، الاسم والعملة، والنسخ الاحتياطي |

## التقرير الشهري

يُبنى تلقائيًا من بياناتك، ويشمل:

- **أرقام الشهر**: المهام المنجزة ونسبة الإنجاز، عدد الالتزامات، الساعات المجدولة، المحصّل وغير المحصّل.
- **مقارنة بالشهر الماضي** في كل رقم رئيسي.
- **جدول توزيع الشهر على المجالات**: مواعيد، ساعات، مهام، نسبة إنجاز، ومبالغ لكل مجال.
- **أبرز ما أنجزته** مع قائمة المهام المنجزة بالتفصيل.
- **سلبيات لازم تُتلافى**: مهام تجاوزت موعدها، مهام أُنجزت متأخرة، مواعيد فاتت أو مضت بلا تعليم،
  مستحقات لم تُحصّل، مجالات مهملة، وأيام محمّلة فوق الطاقة — ومع كل سلبية **علاج مقترح**.
- **توصيات للشهر القادم**.
- **ملاحظاتك الشخصية** تُحفظ مع التقرير في الأرشيف.

أول ما يبدأ شهر جديد يظهر لك شريط في الأعلى: «تقرير الشهر الماضي جاهز».

> لكي يكون التقرير دقيقًا: علّم على المواعيد بعد انتهائها (**تم** / **فات**)، وعلّم المهام حين تنجزها.
> المواعيد المتكررة (الدوام والمحاضرات) لا تُحتسب عليك في بند «مضت بلا تعليم».

---

## المواعيد المتكرّرة

الدوام والاجتماع الأسبوعي والحلقة لا تُدخل مرة كل أسبوع — أدخلها مرة واحدة واختر التكرار:

- **يومي**
- **أسبوعي** مع تحديد الأيام (مثال: الأحد–الخميس للدوام)
- **شهري** (يثبّت اليوم ولا ينزلق آخر الشهر)
- مع **«يتكرر حتى»** اختياري

كل مرة من مرات التكرار لها حالتها المستقلة: تقدر تعلّم أن اجتماع هذا الأسبوع تم، والذي قبله فات.

## البيانات والنسخ الاحتياطي

تُحفظ في `localStorage` على الجهاز نفسه — لا تُرفع لأي خادم.

- **تنزيل نسخة**: الإعدادات ← «تنزيل نسخة (JSON)».
- **نقل البيانات لجهاز آخر**: نزّل النسخة، ثم في الجهاز الآخر «استيراد نسخة».
- نزّل نسخة كل فترة؛ مسح بيانات المتصفّح يمسح كل شيء.

## البنية

```
index.html              الهيكل والشاشات
manifest.webmanifest    إعدادات التثبيت على الجوال
sw.js                   عامل الخدمة (العمل بدون إنترنت)
assets/
  styles.css            التنسيقات (فاتح/داكن، RTL، تنسيق طباعة التقرير)
  util.js               التواريخ، التاريخ الهجري، صياغة الجمع العربي، التنسيق
  store.js              طبقة البيانات: المجالات، الأحداث والتكرار، المهام، التقارير
  ui.js                 المكوّنات المشتركة: النوافذ، البطاقات، التنبيهات
  forms.js              نماذج إدخال الحدث والمهمة والمجال
  views.js              شاشات اليوم والتقويم والمهام والمالية والإعدادات
  report.js             تحليل التقرير الشهري وعرضه
  app.js                التوجيه وربط الأفعال والإقلاع
```

```
build.sh                 يبني نسخة الملف الواحد في dist/
```

جافاسكربت خالص بلا أي اعتماديات. `build.sh` اختياري — التطبيق يعمل من `index.html` مباشرة.
